# 3 sum

My code looks kinda convoluted but it seems to perform well. Basically, I treated it like twoSum, except we have 1 more value that we need to take into account. Since the total sum needs to be 0, I started by sorting the list (that means we only really have to iterate until we hit 0). We start by iterating from the left side (the negative side), with an i pointer,  and then we perform a twoSum on the remainder of the list, where the target is -nums[i]. We return all pairs in the twoSum, and we have a set that takes care of duplicates. Unfortunately, we have to do some weird tuple-ing and untuple-ing things in order to store these pairs in a set because lists are modifiable and tuples are immutable (basically you can't have lists in sets). In order to prevent more duplicate issues, two sum orders the tuples.
