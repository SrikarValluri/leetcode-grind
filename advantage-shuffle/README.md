# advantage shuffle

This problem has two lists, num1 and num2, and the goal is essentially rearrange num1 such that it beats as many values in num2 as possible. In order to do this, a great solution is to sort num1 from lowest to highest and store itself in a deque (so it's easy to pop leftmost and rightmost). Then, sort num2 from largest to smallest while keeping track of the indices . Basically we want to ensure that the highest value in num1 beats the highest value in num2, but if it can't, take an L and sacrifice your smallest value. This a greedy solution. By doing this we can simply update a list (or even num2 in place because we performed list comprehension to generate a new one for the comparisons) with each index from num2 to the winning value (or losing value).
